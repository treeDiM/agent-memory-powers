Un **document technique de référence** traite un sujet technique particulier. Il est créé manuellement par l'utilisateur, mais **maintenu au fil de l'eau par l'agent**. C'est donc une mémoire technique sur une thématique particulière du projet.
Les fichiers sont nommés en kebab-case, **avec un préfixe numérique sur 3 digits** pour faciliter l'ordre d'affichage.

Ce fichier est un index des **documents de référence technique** présents dans ce dossier. 
Cette liste est maintenue à jour par l'agent.
