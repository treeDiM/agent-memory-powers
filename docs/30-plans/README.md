Les **plans d'exécution** sont produits par **Superpowers** après validation d'une **spécification** (`20-specs`). Un plan décrit *comment* faire le travail : découpage en tâches, fichiers touchés, contenu exact à écrire, commandes de vérification et point de commit. Il s'exécute tâche par tâche, avec une revue entre chacune.

Ce fichier est un index des **plans d'exécution** présents dans ce dossier. 
Cette liste est maintenue à jour par l'agent.
