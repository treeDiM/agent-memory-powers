Une **étude** est un document ponctuel qui analyse soit le fonctionnement du dépôt (code, setup, intégration), soit un sujet général (composant tiers, technologie, problème rencontré chez un client). Elle est rédigée par l'agent **à la demande de l'utilisateur** et reflète l'état du dépôt **à sa date de rédaction** : elle n'est pas maintenue au fil de l'eau, contrairement aux `50-technical-references`.

Ce fichier est un index des **études** présentes dans ce dossier.
Cette liste est maintenue à jour par l'agent.
