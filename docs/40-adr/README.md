Un **Architecture Decision Record (ADR)** est la mémoire d'une décision prise, avec son contexte, ce qui a été retenu, les conséquences et les alternatives écartées. Une ADR n'est pas réécrite quand la
décision change : on en crée une nouvelle qui la remplace. L'ADR est horodatée à date d'adoption de la décision. Une ADR est **proposée par l'agent ; sa création est confirmée par l'utilisateur**.

Ce fichier est un index des **ADR** présentes dans ce dossier. 
Cette liste est maintenue à jour par l'agent.
