Index des répertoires du dossier `docs/`.
# Contenu

* `00-knowledge-base/` : base de connaissance générale.
* `05-draft/` : brouillons en cours de rédaction, hors flux.
* `07-studies/` : études ponctuelles, non maintenues au fil de l'eau.
* `10-work-items/` : analyses de demandes. 
* `20-specs/` : Superpowers écrira ici ses spécifications.
*  `30-plans/` : Superpowers écrira ici ses plans d'exécution.
* `40-adr/` : Architecture Decision Record 
* `50-technical-references/` :  documents techniques de référence.
