Un document de la **base de connaissance** constitue une mémoire **durable** d'un invariant lié au
métier ou au projet. Il permet notamment de documenter des points de vocabulaire via un `010-glossary.md`. 
Les fichiers sont nommés en kebab-case, **avec un préfixe numérique sur 3 digits** pour faciliter l'ordre d'affichage.

Ce fichier est un index des documents de la **base de connaissance** présents dans ce dossier.
Cette liste est maintenue à jour par l'agent.
