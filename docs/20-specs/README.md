Les **spécifications** sont produites au terme d'un brainstorming sur un **work item** (`10-work-items`), qui a été classé `architectural` par **Superpowers**. Une spécification décrit *ce qui doit être vrai* une fois le travail fait (décisions arrêtées, comportements attendus, etc.). 
Ces spécifications vont donner lieu à la production d'un **plan d'exécution** (`30-plans`).

Ce fichier est un index des **spécifications** présentes dans ce dossier. 
Cette liste est maintenue à jour par l'agent.
